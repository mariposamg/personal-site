# Personal site – Aminata Mariétou GUEYE

Personal website of Aminata Mariétou GUEYE, Data & AI Solution Architect and Microsoft Certified Trainer.

Static site (HTML, CSS, a few lines of JavaScript). No build step. Hosted on GitHub Pages.

## Structure

```
index.html          # the whole page
assets/style.css    # styles
assets/main.js      # project filters
assets/portrait.jpg # profile photo
assets/favicon.svg  # favicon
.nojekyll           # serve files as-is on GitHub Pages
```

## Run locally

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deploy

Settings → Pages → Source: "Deploy from a branch" → `main` / root.

Technical articles live on [amgueye.dev](https://amgueye.dev).
